## Steps on How to Create GitHub Page

1. Create a GitHub Repository (It must be public)
2. Find a directory in which you want to store your project
3. **Clone** your newly created repository
4. Create your webpage. Make sure it contains and **index.html file**
5. **Add, Commit and Push** your changes to GitHub
6. Go to your repository settings
7. Go to pages, which is under code and automation
8. Select your main branch in the branch section then hit **save**
9. you are now done!
